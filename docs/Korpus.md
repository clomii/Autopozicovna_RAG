# Pôvod a obsah korpusu

Korpus bol vytvorený ako súbor fiktívnych prevádzkových dokumentov pre školský
projekt. Všetky PDF majú textovú vrstvu a dve strany. Údaje nie sú skopírované
z podmienok skutočnej požičovne.

| PDF | Strana 1 | Strana 2 |
| --- | --- | --- |
| 01_rezervacie.pdf | Vytvorenie rezervácie | Úprava potvrdenej rezervácie |
| 02_podmienky.pdf | Vek, prax, doklady | Ďalší vodič |
| 03_cennik_a_zalohy.pdf | Denná sadzba, výška zálohy | Uvoľnenie zálohy |
| 04_prevzatie_a_vratenie.pdf | Preberací protokol | Meškanie a bezkontaktné vrátenie |
| 05_poistenie_a_poskodenie.pdf | Spoluúčasť a balík Plus | Evidencia poškodenia |
| 06_palivo_a_kilometre.pdf | Plná–plná a paušál | Limit km a sadzby |
| 07_pobocky_a_jednosmerny_prenajom.pdf | Otváracie hodiny | Jednosmerné poplatky |
| 08_storno_a_predlzenie.pdf | Zrušenie rezervácie | Predĺženie nájmu |
| 09_zahranicie_a_prislusenstvo.pdf | Výjazd a súhlas | Sedačka a reťaze |
| 10_firemne_prenajmy_a_faktury.pdf | Firemná objednávka | Elektronická faktúra |

OWL/XML je export ontológie z prvého zadania. Je zachovaný bez úprav.
Z OWL pochádzajú identifikátory vozidiel, ich denné ceny, modelové prenájmy,
pobočky a definície tried. Z PDF pochádzajú fiktívne prevádzkové pravidlá.
Metodický článok Databricks sa do vyhľadávacieho korpusu nepridával.
